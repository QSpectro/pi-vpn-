# Pi-VPN WireGuard Home VPN Lab

## Project Overview

This project documents the setup and configuration of a personal home VPN lab using a Raspberry Pi, PiVPN, and WireGuard.

The goal is to learn how VPN technology works, understand secure remote access concepts, and explore DNS filtering integration with Pi-hole.

## Project Goals

- Install and configure PiVPN.
- Explore WireGuard VPN technology.
- Configure VPN client connectivity.
- Explore Pi-hole DNS integration.
- Document the network architecture.
- Test and document VPN connectivity.
- Apply basic network security practices.

## Network Architecture

The intended network design includes:

- Raspberry Pi hosting the VPN service.
- WireGuard providing the VPN connection.
- Pi-hole providing DNS filtering for VPN clients.
- Home gateway connecting the lab to the internet.

## Security Considerations

- Protect VPN private keys and client configuration files.
- Never publish QR codes containing VPN credentials.
- Do not publish public IP addresses, private network details, or passwords.
- Use strong authentication and keep software updated.
- Only connect devices and networks that I am authorized to access.
